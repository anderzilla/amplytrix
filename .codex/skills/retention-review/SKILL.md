# Retention review

Read `docs/source-of-truth/{product,monetization,gamification,privacy}.md`. Identify recurring user outcome, accumulated legitimate value, churn cause, metric and trust guardrails. Test pause, downgrade, cancellation and export. Block data captivity, punitive loss, notification coercion or hidden exit. Recommend reversible value-building experiments.
