# AI agent evaluation

Version agent/model/prompt/tools/policy. Build representative, adversarial and edge-case datasets without production secrets; define deterministic graders where possible and calibrated human rubric otherwise. Measure task success, groundedness, unsafe action, permission violations, injection resistance, latency and cost with thresholds/confidence. Compare baseline, inspect failures and record artifacts. No sensitive capability ships after a safety regression without human decision.
