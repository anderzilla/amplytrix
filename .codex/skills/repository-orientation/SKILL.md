# Repository orientation

1. Read `PROJECT_CONSTITUTION.md`, `AGENTS.md`, root/module READMEs and relevant ADRs.
2. Run Git status and inventory tracked/untracked files; preserve unrelated work.
3. Inspect manifests, dependency graph, affected tests/docs and tool versions; never read secrets.
4. State current state, constraints, risks, assumptions, open questions, plan, and validations.
   Complete only when scope and evidence are recorded before edits.
