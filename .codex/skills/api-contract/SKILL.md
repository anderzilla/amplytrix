# API contract

Identify consumer/use case and authorization. Define resource semantics, schemas/examples, validation, stable error envelope, correlation, pagination/filtering, rate limits and idempotency for retries. Avoid domain/provider leakage. Evaluate backward compatibility and deprecation/migration. Update OpenAPI, schema tests and docs together. Complete when contract validates and negative/security cases are testable.
