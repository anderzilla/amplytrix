# Incident runbook

Define trigger/symptoms, severity, owner/escalation and safe prerequisites. Add detection queries/dashboards, diagnosis decision tree, containment that preserves evidence, remediation, recovery validation, communication/legal checkpoints, rollback/failover, data reconciliation and post-incident actions. Commands must be bounded and mark destructive/production steps as human-approved. Dry-run non-destructively. Complete when an unfamiliar on-call can act safely.
