# Prompt injection review

Map instruction hierarchy, untrusted sources, tools, secrets and egress. Test direct/indirect injection, encoded/obfuscated instructions, data-to-instruction confusion, tool-argument manipulation, cross-tenant retrieval, approval bypass and output exfiltration using synthetic canaries. Verify isolation, allowlists, schemas, least privilege, redaction, approval and audit. Report reproducible evidence safely; critical tool/secret escape blocks release.
