# Feature specification

Define persona/JTBD, problem evidence, outcome/metric, scope and exclusions, user flow, business rules, acceptance examples, data class/retention, threats/abuse, accessibility, observability, cost, rollout/rollback and dependencies. Resolve ambiguity or record open questions; create proposed ADRs for structural choices. Complete when engineers and QA can implement/test without guessing product intent.
