# Accessibility review

Read `docs/source-of-truth/accessibility.md` and affected UI. Run available automated checks, then manually verify keyboard/focus, semantics, screen reader path, contrast, targets, forms/errors, motion, zoom, language/headings/labels. Report criterion, location, reproduction and remedy. Severe critical-flow failures block homologation; automation alone cannot approve.
