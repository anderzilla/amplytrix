# Bounded-context discovery

Use Event Storming/scenarios and glossary conflicts. Classify subdomains; group coherent models by language, ownership, transaction, security and lifecycle; assess value, dependencies, complexity, revenue, MVP and outsourcing. Define published contract/ACL and context relationships. Avoid one context per entity or organization chart. Record candidates as proposed until human/domain validation.
