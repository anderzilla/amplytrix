# Pull request review

Orient, read spec/ADR and inspect complete diff plus surrounding code. Prioritize data loss, security, correctness, concurrency, compatibility and boundary violations; then tests/observability/docs/simplicity. Run non-mutating relevant checks. Report only actionable findings with severity and exact file/line/consequence; disclose unchecked areas. If none, state residual risks rather than generic approval.
