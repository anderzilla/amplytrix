# Dependency evaluation

State use case/owner and compare platform/existing code plus at least one alternative. Verify current maintenance, license, advisories, transitive/install-script/provenance risk, Node/Cloud Run compatibility, bundle/runtime/container/network/data/cost, lock behavior and exit path. Prefer minimum capability. Record decision/ADR when structural, update lockfile, run gates and scan. Complete with evidence and removal owner.
