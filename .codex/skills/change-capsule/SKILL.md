# Change capsule

Link the current baseline and triggering evidence. Record cause, preventability, alternatives,
benefits, risks, client effort, schedule/cost/scope impact, dependencies, rollback, and the option to
decline or defer. Keep the original baseline intact. No agent may accept the capsule, modify a
contract, create financial obligation, or resume blocked execution; obtain the named human decision
and create a new baseline version when approved.
