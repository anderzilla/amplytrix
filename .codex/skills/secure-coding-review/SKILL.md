# Secure coding review

Map changed trust boundaries/assets. Check authentication and deny-default authorization, tenant scoping, validation/encoding, injection, CSRF/SSRF/XSS, mass assignment, secrets/logs/errors, concurrency/idempotency, dependencies and abuse/rate/cost controls. Run relevant non-destructive scanners/tests. Report severity, exact evidence, exploit consequence, remediation and verification; distinguish residual risk. Complete after findings are actionable and no secrets are reproduced.
