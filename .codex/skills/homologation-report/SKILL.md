# Homologation report

Use `docs/templates/homologation-report.md`. List agents/skills actually executed, commands/evidence, finding severity/location/flow/remedy, missing checks, result and approval conditions. Never claim an agent or test ran when it did not. BLOCKER/CRITICAL/HIGH yield FAIL; MEDIUM yields NEEDS_JUSTIFICATION unless corrected/approved.
