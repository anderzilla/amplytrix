# Definition of done

Compare request/spec and exclusions to diff. Confirm acceptance and negative cases, relevant format/lint/typecheck/tests/build/scans, architecture/contracts/migrations/docs/diagrams/threats/observability/rollback, no secrets/unrelated changes, and human approvals. Report command results and skipped checks. Return complete only if no required work remains; otherwise list blockers and next owner. Never equate generated files or passing one test with completion.
