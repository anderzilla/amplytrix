# Domain modeling

Start from scenarios and ubiquitous language. Assign bounded context/owner; identify invariants and transaction boundary before entities; use value objects for validated concepts; define commands, results, domain events and failure vocabulary. Keep provider/ORM/HTTP types outside domain. Test invariants and concurrency assumptions. Complete with diagrams/docs and no anemic abstractions without a stated reason.
