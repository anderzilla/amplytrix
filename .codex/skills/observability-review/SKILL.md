# Observability review

Start from failure/user journey. Verify structured events, service/version/environment, trace and correlation propagation, actionable errors without secrets/PII, bounded label cardinality, latency/error/traffic/saturation metrics, sampling, dashboards/alerts with owner and runbook. Test a failure path and cross-service correlation where possible. Complete when operators can detect, localize and act without sensitive data.
