# Develop-to-homolog gate

Run only for `develop -> homolog`. Read `docs/source-of-truth/testing.md` and `docs/testing/develop-to-homolog-checklist.md`. Execute applicable build/lint/types/tests, architecture, docs, contract, migration, privacy/security, UX/accessibility/i18n/visual/usability/user-communication/abuse/monetization/ethical-persuasion/commercial-integrity/gamification reviews. Block deception, abuse, illegal/immoral practice, dark pattern, obscure charge/renewal, inadequate consent, false urgency/scarcity/proof/message, artificial dependency, harmful gamification, autonomy/privacy violation, obstructed cancellation/export or capability mismatch. Produce the homologation template report. BLOCKER/CRITICAL/HIGH block; MEDIUM needs correction or approved justification. Never fabricate unavailable evidence.
