# Construção da Amplytrix

First complete dogfood project for the Amplytrix method. This package is the Phase Zero operating
record; it is not a customer portal or production database.

Flow: intake -> readiness -> sources -> discovery -> scenarios -> human baseline -> plan -> execution
evidence -> independent supervision -> acceptance. Facts, assumptions, decisions, and evidence stay
distinct. Work outside the accepted baseline requires a change capsule.

Current status: baseline approved for repository-only Phase Zero. No cloud resource, provider, MCP,
personal data, credential, deployment, merge, purchase, contract, or payment is authorized.
