# Quality gates

Frontend PR gate: deterministic pnpm install, Prettier, ESLint, strict TypeScript, tests and Next build. Backend gate: locked uv sync, Ruff format/lint, Pyright strict, Pytest including architecture and applicable PostgreSQL integration tests, Import Linter, Alembic graph/check, deterministic FastAPI OpenAPI snapshot, Bandit, Semgrep, pip-audit, Docker build/smoke/non-root and container scan. Infrastructure: Terraform fmt/validate/Checkov and secret scan. Release additionally needs E2E/smoke, SBOM, no unresolved critical vulnerability, migration/rollback and approval. New critical domain logic targets >=90% branch coverage; broader backend baseline begins at 85% with justified declaration-only omissions.

Branch policy is required on every PR. `develop -> homolog` additionally runs the dedicated gate and manual checklist. BLOCKER/CRITICAL/HIGH block; MEDIUM requires correction or approved justification; LOW/INFO may become owned debt. Unsafe migrations, stale required documentation/contracts, severe accessibility/i18n/visual/usability/communication defects, injection or missing sensitive-flow abuse protection block homologation.
