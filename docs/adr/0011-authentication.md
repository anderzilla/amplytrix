# ADR-0011: Managed authentication strategy

Status: proposed — 2026-08-01

Prefer Google Identity Platform if enterprise SSO/multi-tenancy roadmap and pricing justify it; Firebase Auth is the simpler Google path, while Auth.js offers portability but transfers security operations to the team. Decide from Brazilian residency/LGPD, MFA, account linking, SSO/SCIM, exportability, cost, and server verification. No authentication is implemented.
