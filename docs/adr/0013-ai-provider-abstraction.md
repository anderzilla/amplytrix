# ADR-0013: Provider-neutral AI execution

Status: proposed — 2026-08-01

Define capability-based model ports, normalized usage/cost, prompt versions, evaluation datasets, redaction, policy checks, tool permissions, approval checkpoints, and audit events. OpenAI, Gemini, Anthropic, or local models are adapters selected only after legal, data, quality, latency, and cost evaluation. No real calls in Phase Zero.
