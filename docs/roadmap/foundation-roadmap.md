# Foundation roadmap

Phase Zero: govern the "Construção da Amplytrix" dogfood project using versioned schemas,
capability/MCP registries, allowed sources with provenance, scenarios, an approved baseline, execution
plan, evidence, independent supervision, decisions, and change capsules. Deterministic repository
gates precede persistence, API, UI, or provider work.

Next milestone: Event Storming plus one project-governance walking slice using synthetic data and an
identity fake. Resolve identity, project isolation, retention, legal, and SLO questions before schema
or cloud work. Implement persistence/API only for the selected slice, with PostgreSQL integration
tests, telemetry, threat updates, and rollback. Cloud provisioning, customer portal, operations
console, billing, marketplace, and real AI/MCP calls remain separately gated.
