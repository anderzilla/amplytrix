# Incident response

1. Declare severity/commander and preserve timestamps/evidence.
2. Contain safely: disable affected integration, revoke scoped credentials, stop automation; do not destroy evidence.
3. Assess affected tenants/data/time window and legal notification duties.
4. Eradicate, patch, rotate, restore from verified backup, and smoke test.
5. Communicate through approved legal/security contacts; record uncertainty.
6. Recover gradually with monitoring and rollback.
7. Complete blameless review with owners/dates and update threats/tests/runbooks.
