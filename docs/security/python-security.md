# Python backend security baseline

Prohibit unsafe pickle/yaml deserialization, `eval`/`exec`, shell-composed subprocesses, unvalidated paths/URLs, insecure redirects, debug tracebacks and broad swallowed exceptions. Uploads require type/size/path isolation; XML uses hardened parsers; regex and payload sizes are bounded. SQL uses typed SQLAlchemy parameterization and explicit field mapping. Every outbound HTTP adapter defines connect/read/total timeout, bounded retry with jitter only for safe operations, destination/redirect allowlist, response-size cap, correlation and redaction; circuit breakers are added from measured failure risk. CORS/cookies/JWT/tenant authorization are deny-default and server enforced. AI tools receive scoped capabilities, token/cost ceilings, untrusted-content separation and human approval for sensitive actions.
