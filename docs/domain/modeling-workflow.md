# Modeling workflow

1. Frame business outcome, actors and evidence.
2. Run Event Storming: commands, events, policies, hotspots and external systems.
3. Refine ubiquitous language and subdomain classification.
4. Propose contexts by language, ownership, transactions and change cadence.
5. Map relationships, published contracts and ACLs.
6. Design only required aggregates/invariants and application command/query handlers.
7. Test examples and boundary rules before choosing persistence/transport mapping.
8. Record structural decisions in ADRs and revisit with production learning.
