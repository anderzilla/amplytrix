# Ubiquitous language

| Term             | Working meaning                                                                     | Avoid conflating with  |
| ---------------- | ----------------------------------------------------------------------------------- | ---------------------- |
| Catalog Item     | Versioned offering metadata for an agent, skill, workflow, prompt, template or tool | Executable definition  |
| Agent Definition | Governed instructions, capabilities and permissions for execution                   | Model/provider         |
| Skill            | Reusable bounded procedure and resources                                            | Human competency       |
| Execution        | One auditable attempt to produce an outcome                                         | Conversation           |
| Technical Memory | Project-scoped, governed engineering knowledge                                      | Raw chat history       |
| Evidence         | Verifiable file, command, contract, trace or source supporting an output            | Unattributed assertion |
| Entitlement      | Permission derived from plan/organization policy                                    | Authentication role    |
| Tenant           | Isolation boundary, likely organization                                             | User account           |
| Usage Record     | Immutable measured resource consumption                                             | Invoice line           |

Changes require domain review and update of contracts/examples where the term appears.
