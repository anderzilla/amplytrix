# Official commercial catalog

Catalog records are configuration, never application conditionals. Every item has immutable UUID, stable code and slug, type, category, persona, semantic version, lifecycle status, short and commercial descriptions, requirements, estimated cost class, usage metric, billing unit, configurable limits, granting plan versions, dependencies, experiment flags, availability window, publication/retirement/replacement, security controls, human-approval policy and `commercial_visibility` (`internal|free|trial|paid|premium|invite_only|deprecated`). Executable definitions remain separate.
