# Plan matrix

All grants and limits reference immutable plan versions and entitlement definitions. Values are seed hypotheses, editable through governed administration.

| Capability          | Free                     | Pro Trial       | Pro                   | Team                      | Premium Architecture                     |
| ------------------- | ------------------------ | --------------- | --------------------- | ------------------------- | ---------------------------------------- |
| Users/workspace     | 1/1 personal             | Pro temporarily | 1/personal            | configurable seats/shared | Team plus governed organization          |
| Repositories        | 1 active                 | trial limit     | configurable multiple | shared/configurable       | elevated/configurable                    |
| Ask Project         | 20/month hypothesis      | trial quota     | included quota        | pooled quota              | priority/elevated quota                  |
| Agents              | Lite/samplers/checklists | Pro set         | full individual set   | Pro + team administration | architecture/governance/custom set       |
| Memory/docs         | limited/starter          | temporary Pro   | individual            | shared + living docs      | organizational/governed/longer retention |
| Collaboration/audit | no                       | no              | no                    | yes                       | advanced                                 |
| Credits             | limited monthly          | trial pool      | monthly               | pooled/member controls    | elevated, never “unlimited”              |
| Export              | basic                    | Pro             | expanded              | organization              | governed/executive                       |

`Free`, `Pro Trial`, `Pro`, `Team` and `Premium Architecture` are initial plan families. Enterprise is a future negotiated family supported by the model, not MVP scope. Annual savings, prices, taxes, overage and renewal are disclosed before consent and are not fixed in code.
