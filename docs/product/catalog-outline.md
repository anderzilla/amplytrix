# Catalog outline

Each item must declare persona, problem, outcome, delivery format, dependencies, risk, complexity, monetization potential, automation level, and human-review requirement.

| Family                                      | Primary persona/problem              | Outcome/format             | Risk & complexity   | Tier / automation             |
| ------------------------------------------- | ------------------------------------ | -------------------------- | ------------------- | ----------------------------- |
| Development agents                          | Developer; repetitive implementation | reviewed patch + evidence  | High / high         | Pro; supervised               |
| Architecture agents, ADRs, diagrams, memory | Architect; decision drift            | ADR/C4/living graph        | Medium / medium     | Architecture; assisted        |
| Documentation agents/templates              | All; stale knowledge                 | synchronized docs/runbooks | Medium / medium     | Free-Pro; review              |
| Test and security agents                    | QA/security; late defects            | plans, tests, findings     | High / high         | Team; human gate              |
| DevOps/Cloud agents                         | Platform; unsafe operations          | IaC/release evidence       | Critical / high     | Enterprise; approval required |
| Reusable skills/workflows/prompts           | Leads; inconsistent practice         | versioned packages         | Medium / low-medium | Free-Pro; assisted            |
| Project/architecture/document templates     | Teams; setup cost                    | editable artifacts         | Low / low           | Free-Team; automated          |
| Repository analysis tools                   | Leads; weak visibility               | evidence report            | Medium / medium     | Pro-Team; read-only           |

Audience collections cover developers, tech leads, architects, and managers/companies. Plans: Free discovery assets; Pro individual advanced assets; Team collaboration/governance; Architecture/Enterprise policy, audit, SSO, and support. Entitlements remain unimplemented pending validation.
