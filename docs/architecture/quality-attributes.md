# Quality attributes

Priority order: security/privacy, correctness, operability, evolvability, performance, cost. Initial measurable proposals: no critical known vulnerability at release; all sensitive actions attributable; health response under 500 ms at p95 excluding cold start; monthly availability target defined before beta; restore drill before production; scale-to-zero outside production; critical user flows meet WCAG 2.2 AA. SLOs require traffic evidence before acceptance.
