# Glossary

- **develop**: integration branch receiving task and architecture PRs.
- **homolog**: candidate accepted for manual and automated homologation.
- **master**: production-approved default branch.
- **source of truth**: compact current operational decisions.
- **ADR**: immutable historical decision and rationale.
- **healthy retention**: recurring use caused by recurring value.
- **dark pattern**: interface or communication designed to subvert informed choice.
- **guardrail metric**: harm/cost/trust metric that constrains optimization.
- **project**: isolated unit containing authority, sources, decisions, work, evidence, and acceptance.
- **source of truth (project)**: versioned set of allowed sources and decisions with provenance.
- **scenario**: comparable option stating gains, trade-offs, client effort, risk, time, cost, and consequences.
- **baseline**: human-approved scenario snapshot that fixes scope, price, schedule, and acceptance.
- **capability**: versioned agent, skill, MCP, or template admitted for a defined project scope.
- **change capsule**: governed microproject for an unforeseen or out-of-baseline change.
- **evidence**: traceable favorable, contrary, or inconclusive observation supporting a claim or gate.
- **managed service**: engagement in which CodeMatrix conducts discovery through final acceptance.
