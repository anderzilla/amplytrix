# Testing

Risk determines unit, application, PostgreSQL integration, contract, HTTP, architecture, E2E, accessibility, visual, security, abuse and performance evidence. `BLOCKER`, `CRITICAL` and `HIGH` block; `MEDIUM` needs correction or recorded justification; `LOW`/`INFO` may become owned debt. Build, lint, types, tests, docs and relevant scans must pass before promotion. See ADR-0015 and `docs/testing/`.
