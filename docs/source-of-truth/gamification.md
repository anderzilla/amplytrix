# Gamification

Use progress, checklists, learning paths, proficiency levels, achievements, milestones, optional missions, technical challenges, configurable goals, self-comparison, verified productivity history and legitimate loyalty/referral benefits only to accelerate onboarding, teach capabilities and reinforce useful outcomes. Mechanics must explain rules, benefit and cost, support accessibility, allow notification control and withstand abuse review.

Do not punish pauses, create artificial social pressure, humiliating rankings, anxiety, guilt, fear or shame; coerce with progress loss; obscure mechanics; force/excessively send notifications; manipulate probability; use random financial rewards, loot boxes or betting-like mechanics; inflate metrics; or reward usage/cost without benefit. Optimize objective completion, time to value, saved time, reduced errors, quality, collaboration, satisfaction and healthy retention—not screen time.
