# Gamification

Use milestones, progress, optional missions, recommendations, achievement, useful-history and loyalty/referral benefits only to reinforce legitimate outcomes. Do not punish pauses, create anxiety, coerce with progress loss, obscure mechanics, force notifications, manipulate probability, use loot boxes, resemble gambling or reward valueless consumption. Prioritize activation, time to value, useful retention, satisfaction, objective completion, saved time and reduced errors.
