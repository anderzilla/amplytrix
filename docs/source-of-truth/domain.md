# Domain

The project is the unit of governance, isolation, provenance, authorization, execution, evidence, and
acceptance. Its approved baseline is immutable; a change requires a linked change capsule and human
decision. Contracted capability and project policy define agent autonomy. Absence or inconclusive
evidence requires review rather than an invented conclusion.

Candidate contexts remain hypotheses until Event Storming. Contexts own language, invariants,
transactions, and internals; cross-context access uses published application ports/versioned
contracts. Domain is framework-free. Domain, application, HTTP, persistence, and provider models
remain separate. See ADR-0030–0033, ADR-0039, and ADR-0062.
